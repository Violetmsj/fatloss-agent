# 长期记忆人工测试对话

## 准备隔离环境

构建安装包后，使用独立的 `DSH_HOME` 和测试 profile 安装；示例中的临时目录每次新建，不复用日常数据：

```sh
npm run pack:plugin
TEST_DSH_HOME=$(mktemp -d /tmp/fatloss-memory-check.XXXXXX)
DSH_HOME="$TEST_DSH_HOME" dsh plugin --profile web add "$PWD/dist/dsh-plugin-fatloss-agent-0.1.3.tgz"
DSH_HOME="$TEST_DSH_HOME" dsh web
```

在测试宿主配置可用模型，使用虚构成人画像，打开“减脂陪伴”预设。需要知识检索的场景另行配置测试用 Chroma 和嵌入服务。每条台词单独发送，等待回复后再继续。可用 `/memories` 或聊天中的查询工具检查有效记录；需要全部记录时通过聊天明确要求查询。

## 明确记住、跨会话、纠正和删除

依次发送：

1. “请记住，我不喜欢被催促，希望你提醒我时温和一点。”预期保存有原话依据的偏好。
2. 新开减脂会话：“你以后会怎样提醒我？”预期能使用前一会话的偏好。
3. “纠正一下，我接受你直接提醒，但不要责备我。”预期更新原记忆并增加版本，后续采用新偏好。
4. “请忘记我的提醒方式偏好。”预期删除正文和原话副本，有效记忆不再包含它。
5. 新开会话询问提醒方式。预期不能声称仍记得被删除的业务记忆；已有聊天记录仍然存在。

## 普通陈述与空闲提取

新开会话说：“平时我更喜欢散步，不喜欢跑步。”不要求立即记住。回复结束后保持宿主运行并空闲五分钟，再留出最多一分钟等待提取。预期只有有效变更才提示，跨会话查询可见有原话依据的偏好。

## 十轮提取边界

连续十轮分别混入：普通知识问题、假设自己加班、朋友的饮食习惯、请助手举例、尚未接受的建议，以及真实表达的个人偏好。预期只在回答结束且空闲时处理待提取用户消息；助手建议、假设、他人情况、工具结果不应成为事实。没有合格候选时不提示、不新增记忆。

## 阶段状态与期限

说：“最近我在出差，暂时只能在酒店散步。”没有明确期限时，阶段状态从原话时间起默认七天；明确给出截止日期时按 Asia/Shanghai 保存。之后说“出差结束了”，预期纠正或失效对应状态，不再作为当前约束。到期边界由可控时钟的自动测试验证，无需实际等待七天。

## 画像修改仍需确认

说：“我现在体重 78 公斤。”预期展示画像变更并等待确认，不能绕过确认写入画像，也不能把体重另存为长期记忆。取消后画像保持不变。

## 记录结果

记录模型、宿主版本、台词、工具参数、记忆查询结果及异常。自动测试覆盖确定性规则，人工对话用于评估真实模型的语义理解和回复效果。不要把虚构资料发送到日常 profile。
