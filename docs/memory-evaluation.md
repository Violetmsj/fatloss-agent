# 长期记忆验证

`npm test` 使用临时 SQLite、假模型和可控时钟，验证证据、事务、版本冲突、有效期、十轮/空闲调度、超时与取消。测试不会请求真实模型，不能证明模型对每种自然语言都理解正确。

[test/fixtures/memory-evaluation.json](../test/fixtures/memory-evaluation.json) 保留虚构原话、初始记忆、预期动作和人工检查点，作为 DSH 对话验收参考。真实模型效果通过[人工测试对话](memory-manual-dialogues.md)在独立 profile 验证，不提供独立模型评估命令。

记录宿主版本、模型名称、日期、原话、候选和实际记忆。分别检查是否应当记住、记录是否准确、后续回复是否正确使用；不能以入库条数作为质量指标。手动运行真实模型会产生用量。

只自动处理启用后当前会话分支的消息，不扫描所有历史会话。恢复同一会话可继续未完成的处理。空闲提取要求宿主仍在运行；失败会保留进度，在下一次正常触发时重试。
